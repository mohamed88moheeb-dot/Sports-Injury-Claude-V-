# Capacity Knowledge System (v1.0 scaffold) — NON-EXECUTABLE

The governed home for **universal human capacities** — the bridge that connects the other knowledge
systems:

```
Assessment measures capacity
Exercise improves capacity
Activity expresses capacity
Demand profile requires capacity
```

It is built for **everyone** — elite athletes, recreational athletes, active people, non-athletes,
older adults, and anyone returning to daily life, work, the gym, or sport.

**Nothing here is clinically approved, executable, or wired into runtime.** No capacity object creates a
score, threshold, pass/fail decision, timeline, dosage, prescription, progression, readiness, RTT/RTS, or
clearance authority.

## Files
| Path | Purpose |
|---|---|
| `status/capacityKnowledgeStatus.json` | System status (scaffold only, 0 objects) |
| `schema/capacityObject.schema.json` | Inert structural schema (`additionalProperties:false`) |
| `templates/capacityObjectTemplate.json` | Blank, inert template |
| `rf/objects/.gitkeep` | Future RF capacity objects (none yet) |
| `rf/source/rfCapacitySourceMap.json` | Future RF capacity mapping scaffold |

Validate with `npm run validate:capacity-knowledge` (passes with 0 objects).
Master ontology: `docs/implementation/CAPACITY_KNOWLEDGE_SYSTEM_MASTER_ONTOLOGY.md`.

## Governance
Every object is draft / pending / not approved / non-executable / runtime none / metadata only.
Capacity is represented as a qualitative **evidence stack** + **confidence status**, never a single score.
